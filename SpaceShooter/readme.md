## 👾 Sobre o jogo

**Space Shooter** é um jogo de nave espacial desenvolvido para o projeto **RetroGame**, utilizando o **ESP32**.

No jogo, o jogador controla uma nave e precisa enfrentar uma série de **alienígenas inimigos**, utilizando disparos para destruí-los e aumentar sua pontuação.

A proposta foi criar uma experiência simples, inspirada nos clássicos jogos de nave dos antigos videogames.

---

## 🎯 Objetivo

O objetivo principal é **destruir os alienígenas e conseguir a maior pontuação possível**.

O jogador precisa controlar a nave, posicioná-la corretamente e utilizar os disparos para eliminar os inimigos.

Quanto mais inimigos forem destruídos, maior será a pontuação.

---

## 🎮 Controles

| Controle    | Função                             |
| ----------- | ---------------------------------- |
| 🎮 Joystick | Movimenta a nave                   |
| 🔘 Botão 1  | Dispara                            |
| 🔘 Botão 2  | Ação secundária / controle do jogo |

---

## 👾 Inimigos

Os inimigos aparecem na tela e representam os alienígenas que precisam ser destruídos.

O jogador deve evitar colisões e utilizar os disparos para eliminá-los.

---

## ⭐ Pontuação

A pontuação aumenta conforme o jogador consegue destruir os alienígenas.

O sistema de pontuação permite que o jogador tente superar sua própria marca em cada partida.

---

## 💥 Game Over

A partida termina quando o jogador perde todas as suas vidas ou ocorre uma condição de derrota definida pela lógica do jogo.

Após o Game Over, o jogador pode iniciar uma nova partida e tentar obter uma pontuação maior.
