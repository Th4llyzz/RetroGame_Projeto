# RetroGame

O **RetroGame** é um mini videogame desenvolvido como projeto acadêmico utilizando um **ESP32** e componentes eletrônicos, inspirado nos consoles clássicos e na nostalgia dos jogos retrô.

O projeto conta com um **controle composto por um analógico e dois botões**, permitindo ao jogador navegar pelos menus e controlar os jogos disponíveis.

###  Jogos disponíveis

* 🚀 **Space War** — Controle uma nave espacial e enfrente ondas de alienígenas.
* 🧱 **Tetris** — Encaixe as peças e tente completar o maior número de linhas possível.
* 🐦 **Flappy Bird** — Controle o personagem e desvie dos obstáculos pelo caminho.

### 🔧 Componentes utilizados

* ESP32
* Display para exibição dos jogos
* 1x Joystick analógico
* 1x Botões
* Componentes eletrônicos auxiliares

### 🎯 Objetivo

O objetivo do projeto foi aplicar na prática conceitos de **programação, eletrônica e desenvolvimento de sistemas embarcados**, criando um pequeno console capaz de executar diferentes jogos utilizando o ESP32.

**RetroGame — trazendo a nostalgia dos jogos clássicos para um projeto feito com ESP32. 🎮**
