## 📖 Sobre o projeto

O **RetroGame** é um mini videogame desenvolvido utilizando um **ESP32**, criado como um projeto acadêmico com o objetivo de colocar em prática conhecimentos de **programação, eletrônica e sistemas embarcados**.

A proposta foi desenvolver um pequeno console inspirado nos videogames clássicos, utilizando componentes simples e criando diferentes jogos que podem ser executados diretamente no ESP32.

O sistema possui um **joystick analógico e dois botões físicos**, utilizados para navegar pelos menus e controlar os jogos.

---

## 🕹️ Jogos disponíveis

### 🚀 Space WAR

Um jogo de nave espacial onde o jogador precisa enfrentar e destruir alienígenas.

**Objetivo:** conseguir a maior pontuação possível eliminando os inimigos.

➡️ [Ver README do Space WAR](./SpaceShooter/readme.md)

---

### 🧱 Tetris

Uma versão do clássico jogo de encaixe de peças.

**Objetivo:** organizar as peças para completar linhas e conseguir a maior pontuação possível.

➡️ [Ver README do Tetris](./Tetris/README.md)

---

### 🐦 Flappy Bird

Uma versão inspirada no clássico jogo de obstáculos.

**Objetivo:** controlar o personagem e passar pelos obstáculos sem colidir.

➡️ [Ver README do Flappy Bird](./FlappyBird/README.md)

## 🎛️ Controles

O RetroGame utiliza três controles físicos principais:

| Controle    | Função                    |
| ----------- | ------------------------- |
| 🎮 Joystick | Movimentação e navegação  |
| 🔘 Botão 1  | Ação principal            |
As funções podem variar dependendo do jogo.
