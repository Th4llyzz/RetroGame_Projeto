## 📖 Sobre o jogo

**Tetris** é uma versão do clássico jogo de encaixe de peças desenvolvida para o **RetroGame**, utilizando o ESP32.

O jogador deve controlar as peças que aparecem na tela, movimentando e organizando cada uma delas para formar linhas completas.

Quando uma linha é completada, ela é eliminada e o jogador recebe pontos.

---

## 🎯 Objetivo

O objetivo é **sobreviver pelo maior tempo possível e conseguir a maior pontuação**.

O jogador precisa organizar as peças de maneira estratégica para evitar que elas ocupem toda a área disponível.

---

## 🎮 Controles

| Controle                  | Função                     |
| ------------------------- | -------------------------- |
| 🎮 Joystick para os lados | Movimenta a peça           |
| 🎮 Joystick para baixo    | Acelera a queda            |
| 🔘 Botão 1                | Rotaciona a peça           |
| 🔘 Botão 2                | Ação secundária / controle |

---

## 🧱 Peças

O jogo utiliza diferentes formatos de peças que devem ser encaixados no espaço disponível.

Cada peça pode ser movimentada e rotacionada para encontrar a melhor posição.

---

## ⭐ Sistema de pontuação

O jogador recebe pontos ao conseguir completar linhas.

Quanto mais linhas forem eliminadas, maior será a pontuação.

O objetivo é conseguir a maior pontuação antes que o espaço disponível seja preenchido.

---

## 💀 Game Over

O jogo termina quando as peças acumulam até o ponto em que não é mais possível inserir novas peças.

Depois disso, o jogador pode iniciar uma nova partida.

---

## 🧠 Conceitos utilizados

O desenvolvimento do Tetris envolve diversos conceitos de programação:

* Matrizes;
* Movimentação de peças;
* Rotação;
* Detecção de colisões;
* Detecção de linhas completas;
* Remoção de linhas;
* Sistema de pontuação;
* Controle de estados;
* Leitura do joystick;
* Leitura dos botões;
* Atualização do display.
