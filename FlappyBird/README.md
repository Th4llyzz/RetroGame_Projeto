## 📖 Sobre o jogo

**Flappy Bird** é um jogo desenvolvido para o **RetroGame**, inspirado na mecânica do famoso jogo de obstáculos.

O jogador controla um personagem que precisa atravessar os obstáculos presentes no caminho sem colidir.

O desafio aumenta conforme o jogador consegue avançar, exigindo atenção e precisão nos comandos.

---

## 🎯 Objetivo

O objetivo é **percorrer a maior distância possível**, desviando dos obstáculos e acumulando pontos.

Cada obstáculo ultrapassado contribui para o aumento da pontuação.

---

## 🎮 Controles

| Controle    | Função                        |
| ----------- | ----------------------------- |
| 🔘 Botão 1  | Faz o personagem subir        |
| 🔘 Botão 2  | Ação secundária               |
| 🎮 Joystick | Navegação / controle auxiliar |

---

## 🐦 Gameplay

Durante a partida, o personagem se movimenta continuamente pela tela.

O jogador precisa utilizar os controles no momento certo para manter o personagem no caminho correto e evitar os obstáculos.

O desafio está em controlar o movimento e calcular o momento correto para realizar cada ação.

---

## ⭐ Pontuação

A pontuação aumenta conforme o jogador consegue passar pelos obstáculos.

O objetivo é alcançar a maior pontuação possível antes de ocorrer uma colisão.

---

## 💥 Game Over

A partida termina quando o personagem colide com um obstáculo ou ocorre outra condição de derrota definida pelo jogo.

Após o Game Over, o jogador pode reiniciar a partida e tentar superar sua pontuação anterior.
